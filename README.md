# sandbox

Prototype gallery for timmfin.net concepts.

- `/index.html` — local gallery page linking to all 11 HTML sketches.
- `/terminal-xterm` — npm-based xterm.js demo for local development.
- `/pages` — GitHub Pages-ready copy of the gallery and all prototypes (including a CDN-powered xterm.js build).

Configure GitHub Pages to publish from the `/pages` directory so every prototype is available on the live site.
