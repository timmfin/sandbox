# sandbox

Prototype gallery for timmfin.net concepts.

- `/index.html` — local gallery page linking to all 11 HTML sketches.
- `/terminal-xterm` — npm-based xterm.js demo for local development.
- `/pages` — GitHub Pages-ready copy of the gallery and all prototypes (including a CDN-powered xterm.js build).

Publishing options:
- **gh_pages branch:** set the Pages source to the `gh_pages` branch (root) to serve `/index.html` with the prototypes at `/prototypes`.
- **pages directory:** alternatively, point the Pages source at the `/pages` directory on the default branch to use the self-contained copy.

Either path keeps all 11 prototypes linked and ready for hosting.
